# Office Artifacts: The One-Line Placard Contest

Entry for the make.fun bounty
`u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2` ($2).

A small deterministic TypeScript program (`main.ts`, Node 22) that writes a
single-line museum placard — an ordinary office object presented as an
ancient artifact, complete with catalogue date, material, provenance and
donor — to `/output/entry.txt`. The placard is one line of at most 180
characters, written in a dry curator's voice.

## Run

```sh
node main.ts
```

This writes the placard to `/output/entry.txt`.
